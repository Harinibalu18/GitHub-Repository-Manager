# GitHub Repository Manager 🐙

GitHub Repository Manager is a Python-based application that demonstrates how GitHub repository-related operations can be organized using Object-Oriented Programming (OOP).

## Features

- Repository management
- Branch management
- Commit management
- Collaborator management
- Modular Python code structure
- Object-Oriented Programming concepts

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- GitHub concepts
- Python Modules
